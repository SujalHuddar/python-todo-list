# Python To-Do List App

## About
A simple command-line task management application built using Python.

## Features
- Add tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Save tasks using JSON file handling

## Technologies Used
- Python
- JSON
- Lists and dictionaries
- Functions
- File handling

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

   `python todo.py`

## Project Structure
- `todo.py` - Main Python application
- `README.md` - Project documentation
- `tasks.json` - Created automatically when tasks are saved

## Learning Objectives
Practice Python fundamentals, including loops, functions, dictionaries, exception handling, and file handling.
